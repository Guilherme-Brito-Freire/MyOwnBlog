# 🫣 My own blog.

eu fiz esse projeto como teste para aprender sobre uma blibioteca do ecosistema spring
a biblioteca é chamada thymeleaf. Ela permite eu fazer SSR dentro do springboot. A ideia
então era fazer a aplicação mais direta possível, usando a ORM do mongo para simplificar
o banco de dados, e usando o htmx para carregar trechos do html. 🦊

o projeto usa o utilitario do docker, então ele deve ser simples de rodar, e subir todos os
sistemas automaticamente.

## atenção

🏗️ isso se trata de um projeto de testes envolvendo o spring, não use em uma situação séria.
